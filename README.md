# Extrusion Calculator

Mobile-first extrusion production calculator built with React and Vite.

## Local Preview

```bash
npm install
npm run build
npm run preview -- --host 0.0.0.0
```

## GitHub Pages App Install

This project includes a GitHub Actions workflow at `.github/workflows/deploy-pages.yml`.

After the repo is pushed to GitHub:

1. Open the GitHub repo.
2. Go to `Settings` -> `Pages`.
3. Set `Source` to `GitHub Actions`.
4. Push to `main` or `master`.
5. Open the Pages URL on your phone.
6. Use Chrome `Install app` on Android or Safari `Add to Home Screen` on iPhone.

The workflow automatically builds with the correct GitHub Pages base path.
